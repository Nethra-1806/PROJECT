# 🤖 Stylish Chatbot

A simple and interactive **Rule-Based Chatbot** developed using **HTML, CSS, and JavaScript**. The chatbot provides predefined responses to common user messages through a clean and stylish chat interface.

## 📌 Features

* 💬 Interactive chatbot interface
* 🤖 Rule-based responses
* 👤 User and bot message icons
* ⌨️ Send messages using the Send button
* ↵ Press **Enter** to send a message
* 😊 Emoji-supported bot responses
* 📱 Responsive chat container
* 🎨 Stylish gradient background and modern UI
* ⚡ Simulated response delay

## 🛠️ Technologies Used

* **HTML5** – Structure of the chatbot
* **CSS3** – Styling and user interface
* **JavaScript** – Chatbot functionality and responses
* **Font Awesome** – Icons

## ⚙️ How It Works

1. The user enters a message in the input box.
2. JavaScript reads the user's message.
3. The input is converted to lowercase and trimmed.
4. The chatbot checks the message against predefined rules.
5. A suitable response is displayed in the chatbox.
6. If the message is not recognized, the chatbot displays a default response.

The chatbot supports predefined messages such as **"hi"**, **"how are you?"**, **"what is your name?"**, **"bye"**, **"help"**, and **"thank you"**.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Make sure all three files are in the same folder:

   * `HTML code.html`
   * `styles.css`
   * `script.js`
4. Open `HTML code.html` in your browser.
5. Start chatting with the chatbot! 🤖
